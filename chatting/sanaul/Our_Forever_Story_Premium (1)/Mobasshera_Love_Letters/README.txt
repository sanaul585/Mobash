MOBASSHERA LOVE LETTERS
=======================

Files:
- index.html  : Main website
- style.css   : Romantic Pink & White styling
- script.js   : 15 Urdu letters, navigation, scroll progress and mobile menu

How to use:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. Scroll down to read all 15 letters. Use the letter list to jump to a letter.
4. To edit the letters, open script.js and edit the `letters` array.
5. To change colors or layout, edit style.css.

Internet note:
Google Fonts are loaded online for elegant Urdu and English typography. The website itself works offline too, using your browser's fallback fonts if internet is unavailable.

Publishing:
You can upload the extracted files to GitHub Pages or Netlify. Keep index.html, style.css and script.js together in the same folder.
